Сила борошна — вміст білка: чим більше, тим міцніша клейковинна сітка й краще тісто тримає газ. Для закваски й більшості хлібів книги базове — сильне пшеничне.

## Пшеничне
| Вид | Що дає |
|---|---|
| Вищого ґатунку | білий хліб, батони, багети, здоба |
| Першого ґатунку | більше оболонок, ароматніше |
| Другого ґатунку | темніше, виразніший смак |
| Цільнозернове | з усього зерна, клітковина, насичений смак |
| Сильне, хлібопекарське, від 12 % білка | тримає форму; для закваски, чіабати, багета |

## Для закваски
Сильне борошно з м'яких сортів (Т00, Т0) з 13–16 г білка на 100 г. Воно дає закваці їжу, тримає газ і структуру, а потім і хліб виходить міцнішим, з хрусткою скоринкою. Звичайне вищого ґатунку авторка не радить: бродіння повільніше, закваска швидше слабне.

## Інші види
| Вид | Особливість |
|---|---|
| Житнє обдирне чи обойне | найчастіше для заквасок і житнього хліба |
| Житнє цільнозернове | яскрава кислинка, щільний хліб |
| Житнє сіяне | світліше, ніжніше, для змішаних хлібів |
| Спельта (полба) | горіховий смак, хліб пухкий, але піднімається менше за пшеничний |
| Кукурудзяне | без глютену, саме не піднімається; 20–30 % у суміші для кольору й аромату |
| Гречане | без глютену, щільний виразний хліб |
| Вівсяне | м'який солодкуватий смак, слабке, лише в суміші |
| Ячмінне, нутове, рисове, просяне, кіноа | малими частками для смаку й поживності |

## Зберігання
- 15–20 °C, сухо. У спеку старіє й заводяться комахи, у вогкості злежується.
- Скляні банки чи контейнери з кришкою або щільні паперові мішки в закритій шафі. Пластик лише ненадовго: вбирає запахи.
- Від молі й жучків — лавровий лист чи кілька зерен рису в банці.

| Борошно | Термін |
|---|---|
| Біле пшеничне | до 12 місяців |
| Житнє, цільнозернове | 3–6 місяців: зародок з оліями гіркне |
| Гречане, кукурудзяне | 2–4 місяці |

Великий запас цільнозернового тримай у холодильнику чи морозилці.
