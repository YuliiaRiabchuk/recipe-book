Мінімум для закваски й хліба. Ваги потрібні в обох списках: усе міряється в грамах.

## Для закваски
- Скляні банки 0,5–1 л, прозорі, з широким горлом.
- Накриття: пластикова кришка не до кінця, плівка з проколом або серветка з гумкою.
- Кухонні ваги.
- Силіконова чи дерев'яна лопатка.
- Гумка або маркер — відмічати рівень після годування.

## Для хліба
- Миска або тістоміс.
- Ваги.
- Скребок, пластиковий чи металевий, для липкого тіста.
- Кошик для розстійки (банетон): тримає форму й лишає візерунок. Замість ротангового підійде пластикова хлібниця чи контейнер з отворами.
- Лезо для надрізів: тримач із бритвою (lame) або просто лезо.
- Чавунний казан або товстостінна каструля з кришкою: імітує пекарську піч.
- Пергамент: переносити заготовку в гарячий казан.
- Термометр, за бажанням: готовий хліб має 96–98 °C усередині.
- Решітка: хліб остигає, не вогкне знизу.
- Лляний рушник або тканина для розстійки: накривати тісто.
