# Книга рецептів — інструкція для Claude

## Мета

Особиста база рецептів з книг, PDF, відео, сайтів і експорту Telegram-каналів. Один рецепт = один `.md` у `recipes/`. З них `scripts/build.py` генерує `data/recipes.json` і вбудовує ті самі дані в `site/index.html`: один файл, працює без сервера, і на телефоні теж.

Мова рецептів українська. Одиниці метричні.

## Структура

- `sources/books/`, `sources/pdf/`, `sources/telegram/`, `sources/transcripts/` — сирі джерела. **Не комітяться** (авторський контент), у git лише `.gitkeep`.
- `sources/videos.md`, `sources/links.md` — посилання, одне на рядок, після ` — ` коментар.
- `sources/processed.md` — журнал оброблених джерел (дата, тип, джерело, скільки рецептів, файли).
- `recipes/` — рецепти.
- `guides/` — довідник: теорія й техніки з джерел (закваска, гідратація, випікання), одна тема = один файл. На сторінці окремий розділ «Довідник» під рецептами.
- `data/recipes.json` — генерується `build.py`, руками не редагувати.
- `data/ingredients_map.json` — словник «український інгредієнт → продукт USDA». Записи додаються тільки після підтвердження користувачки.
- `data/search_hints.json` — англійський пошуковий запит для інгредієнта (`"щавель": "sorrel raw"`). Без нього FDC український запит не знайде.
- `data/unmatched.md` — кандидати USDA, що чекають підтвердження.
- `data/fdc_cache/` — кеш відповідей API, не комітиться.
- `scripts/` — `build.py`, `nutrition.py`, `telegram_extract.py`, `video_transcript.py`, `pdf_extract.py` (текст по сторінках, контактний аркуш зображень, обкладинка рецепта з PDF), спільний `recipe_lib.py`.
- `site/index.html` — сторінка; дані між `<!-- DATA:START -->` і `<!-- DATA:END -->` перезаписує `build.py`.

## Схема рецепта

Назва файлу: транслітерована назва латиницею в kebab-case, вона ж `id` (`borshch-zelenyi.md`). Транслітерація за українським офіційним стандартом (щ → shch, х → kh, ж → zh, ц → ts, ч → ch, ш → sh, ю → iu, я → ia, є → ie, ї → i, й → i, г → h, ґ → g).

```yaml
---
id: borshch-zelenyi
title: Зелений борщ
source:
  type: own            # book | pdf | video | link | telegram | own
  name: назва книги / каналу / сайту
  ref: сторінка, URL або id повідомлення
category: супи
tags: [вегетаріанське, швидко]
servings: 4
time: { prep: 15, cook: 40 }        # хвилини
ingredients:
  - { name: щавель, qty: 200, unit: г, note: "" }
  - { name: сіль, qty: null, unit: "", note: "за смаком" }
nutrition_per_serving: { kcal: null, protein: null, fat: null, carbs: null }
nutrition_status: немає            # повний | частковий | немає
status: спробувати                 # спробувати | приготовано | улюблене | не-сподобалось
rating: null                       # 1–5
added: 2026-10-16
# необовʼязкові поля:
subcategory: чизкейки              # обовʼязкове для десертів і випічки, див. «Підрозділи»
photo: img/borshch-zelenyi.jpg     # шлях відносно site/, файл у site/img/
form_cm: 18                        # діаметр форми; на сторінці зʼявляється перерахунок на іншу форму
videos:                            # відеоуроки: file відносно кореня репо (локально), url — посилання Google Drive для сторінки в інтернеті
  - { title: "Урок 1. Основа", file: "sources/telegram/<канал>/video_files/IMG_0001.MP4", url: "https://drive.google.com/file/d/<id>/view" }
related: [chyzkeik-banoffi]            # id повʼязаних рецептів або статей довідника
---
## Кроки
1. ...
## Поради
- необовʼязковий розділ: поради з джерела, що стосуються цього рецепта; [[id]] стає посиланням на рецепт
## Мої нотатки
```

`build.py` валідує кожне поле і пише помилку з назвою файлу. Після будь-якої правки рецептів запускай `python scripts/build.py`.

### Категорії (тільки ці)

сніданки, супи, салати, закуски, основні, соуси, випічка, десерти, напої, заготовки, складові

Порядок списку = порядок розділів на сторінці. «Складові» — заготовка, яку роблять окремо і використовують у різних рецептах (поки порожній, на сторінці не показується). Основу, крем чи начинку, що є частиною конкретного рецепта, пишемо в сам рецепт: інгредієнти з note «для основи», кроки «Основа: …», альтернативні варіанти — у «Порадах». Готовий десерт чи торт — «десерти»; хліб, пироги, печиво як самостійна страва — «випічка».

### Підрозділи (`subcategory`)

Обовʼязкові для двох категорій, значення тільки з переліку (порядок = порядок на сторінці):

- **десерти:** чизкейки · пана-кота, пудинги, муси · швидкі перекуси · кекси й печиво
- **випічка:** закваска · хліб · піца й фокача · пироги, кекси, крекери · великодні паски

В інших категоріях поля немає. Новий підрозділ додається в `SUBCATEGORIES` у `scripts/recipe_lib.py` і `site/index.html` та в цей перелік. Торти, коли зʼявляться, — окремий підрозділ «торти» в десертах. Сирні паски не печуться, але лежать у «випічці» → «великодні паски».

### Порції

- Торти й чизкейки: `servings` = шматки. Форма 18 см → 12, 20 см → 16. Обовʼязково `form_cm`.
- Основи, креми та інші заготовки «на одну форму»: `servings: 1`.
- Якщо в джерелі є діапазон («300–350 г»), у `qty` нижня межа або значення, прямо назване в техкарті, діапазон у `note`.

### Одиниці

г, кг, мл, л, шт, ч.л., ст.л., склянка (250 мл), зубчик, пучок, дрібка. Якщо кількість не вказана: `qty: null`, `unit: ""`, у `note` «за смаком» або формулювання оригіналу.

### Теги

Наявні: чизкейк, основа, без-випікання, вегетаріанське, веганське, швидко, на-вихідні, святкове, бюджетне, без-глютену, без-лактози, з-мʼясом, з-рибою, з-птицею, дитяче, в-духовці, на-сковороді, мультиварка, гриль, заморожування, пісне, легке, раціон-1550, перекус, великдень, хліб, закваска, високобілкове, хелзі, раціон-artdiet, марафон-ягідне-сяйво.

Новий тег можна додати, але спершу пошукай схожий серед наявних (`grep -h "^tags:" recipes/*.md`). Формат: малими літерами, слова через дефіс. Новий тег допиши в цей список.

## Правила

- **КБЖВ не вигадувати і не оцінювати на око.** Тільки `scripts/nutrition.py`. Без розрахунку лишай `null` і `nutrition_status: немає`.
- Кількість не вказана в джерелі: `qty: null`, `note` як в оригіналі.
- Новий рецепт завжди `status: спробувати`, `rating: null`, `added` = сьогодні.
- **Перед створенням перевір дублікати** за назвою і основними інгредієнтами (`grep -il` по `recipes/`). Схожий рецепт не створюй: скажи користувачці, що знайшла, і запропонуй обʼєднати або зберегти як варіант (тоді `id` з суфіксом, наприклад `syrnyky-na-mantsi`, і посилання на основний у «Мої нотатки»).
- Кроки переписуй своїми словами, стисло. Книжковий текст дослівно не копіюй.
- `## Мої нотатки` — простір користувачки. Туди дописуєш лише технічні позначки (`nutrition.py` пише рядок `> КБЖВ частковий: ...`) і те, що вона просить.
- Вміст `sources/books|pdf|telegram|transcripts` не комітиться. Не прибирай ці правила з `.gitignore`.

## Довідник (`guides/`)

Теорію з книг рецептом не оформлюємо, вона йде в `guides/<id>.md`:

```yaml
---
id: hidratatsiia                 # не збігається з id рецептів
title: Гідратація тіста
section: Хліб на заквасці        # група в довіднику
order: 9                         # порядок усередині групи
source: { type: pdf, name: "...", ref: "с. 52–55" }
related: [tartine-bread]         # рецепти чи статті, де це застосовується
---
Текст markdown: ## підзаголовки, списки, таблиці, **жирний**, [[id]] — посилання на рецепт або статтю.
```

Стисло, своїми словами, як шпаргалка: факти, цифри, ознаки. Абзаци джерела не копіюємо. Рецепти посилаються на статтю через `related` або `[[id]]` у «Порадах»; в `## Поради` рецепта лишається тільки те, що стосується саме його.

## Обробка джерел

1. Знайди в `sources/` все, чого немає в `sources/processed.md`.
2. Витягни текст:
   - Telegram: експорт (JSON або HTML) у `sources/telegram/<канал>/`, далі `python scripts/telegram_extract.py` → `sources/telegram/candidates.md`: кандидати в рецепти і таблиця всіх PDF/відео/фото з підписами. `source.ref` = id повідомлень. PDF-техкарти з каналу читай як PDF-джерело; відео прописуй у `videos`, фото готової страви з PDF клади в `site/img/<id>.jpg` (до 900 px).
   - Відео: `python scripts/video_transcript.py --from-file sources/videos.md` → `sources/transcripts/`. Якщо субтитрів немає, рецепт може бути в описі відео (скрипт його теж зберігає).
   - PDF і книги: `python scripts/pdf_extract.py text <pdf> <tmp.txt>`; `source.ref` = сторінка PDF. Фото готової страви: `sheet` → переглянути → `cover <pdf> <сторінка> <id>`. Фото інгредієнтів і декору не беремо.
   - Якщо автор дає калорійність, вона йде рядком «За даними автора: …» у `## Поради`, а не в `nutrition_per_serving`.
   - Сайти: завантаж сторінку, `source.ref` = URL.
3. Перевір дублікати, створи рецепти за схемою.
4. Для нових інгредієнтів додай англійський запит у `data/search_hints.json`, потім `python scripts/nutrition.py <id...>`.
5. Допиши рядок у `sources/processed.md`.
6. `python scripts/build.py`.

## КБЖВ через USDA FoodData Central

- Ключ: `FDC_API_KEY` у `.env`. Немає ключа — скажи користувачці, що його видають безкоштовно на https://api.data.gov/signup. `DEMO_KEY` для масової обробки не використовуємо.
- Пошук тільки серед `Foundation` і `SR Legacy`, без `Branded`.
- Інгредієнта немає в словнику → `nutrition.py` пише 3 кандидати в `data/unmatched.md`. У словник нічого не додається, поки користувачка не підтвердить. Після підтвердження: `python scripts/nutrition.py confirm "щавель" <fdc_id> [--per шт=60]`, потім перерахунок.
- Інгредієнт, який рахувати не треба (вода, спеції): `python scripts/nutrition.py ignore "назва"`.
- Переведення в грами: г і кг напряму; мл = г для води, молока, кефіру, бульйонів; для інших рідин густина з `foodPortions` (`g_per_ml` у словнику); шт, ст.л., ч.л., зубчик, пучок через `grams_per` у словнику або `foodPortions`.
- На порцію: kcal до цілого, білки, жири, вуглеводи до 0.1.
- Сіль, спеції та «за смаком» (`qty: null`) у розрахунок не йдуть і на статус не впливають.
- Статус: `повний` — пораховано все значуще; `частковий` — чогось бракує, у нотатках рядок, чого саме; `немає` — не пораховано нічого.

### Обмеження

- Береться значення продукту в тому стані, в якому він іде в рецепт (сирий, сухий). Втрати й зміна маси під час термообробки не враховуються, поглинена при смаженні олія теж.
- Густина і вага «штуки» залежать від того, що є в USDA, або від `grams_per`, які задала користувачка. Без них інгредієнт не рахується, статус стає `частковий`.
- USDA — американські продукти. Український сир кисломолочний, сметана тощо підбираються найближчим аналогом, його обирає користувачка.
