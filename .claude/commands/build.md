---
description: Перезібрати дані й сторінку, закомітити та запушити
---

1. `python scripts/build.py`. Помилки валідації: покажи їх і зупинись, нічого не коміть.
2. `git status --short`. Переконайся, що в індекс не потрапляє нічого з `sources/books|pdf|telegram|transcripts` (окрім `.gitkeep`), `.env` і `data/fdc_cache/`. Якщо таке зʼявилось, зупинись і скажи.
3. Подивись `git diff --stat` і склади повідомлення коміту українською за змістом змін, наприклад: `Додано 3 рецепти з каналу «Смачно»: сирники, деруни, вареники`, `КБЖВ для борщу зеленого`, `Оцінка сирникам: 5`. Без загальних «update».
4. `git add -A`, `git commit -m "..."`, `git push`.
5. Відповідь: повідомлення коміту і що запушено.
